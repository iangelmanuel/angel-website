# Lúdico BQ

Lúdico BQ es un sitio web profesional desarrollado para un consultorio de terapia ocupacional infantil especializado en alimentación sensorial, selectividad alimentaria e integración sensorial. La plataforma está diseñada para informar a los padres, generar confianza y facilitar la captación de nuevos pacientes mediante una experiencia digital clara, profesional y centrada en el usuario.

El proyecto busca posicionar a Lúdico como un referente en terapia de alimentación infantil en Barranquilla, destacando la experiencia de más de 20 años de la terapeuta ocupacional Jazmín Rojas.

## Funcionalidades Clave

- **Presentación de Servicios**: Información clara sobre terapia de alimentación, integración sensorial y acompañamiento familiar
- **Perfil Profesional**: Sección dedicada a la experiencia, formación y enfoque terapéutico de Jazmín Rojas
- **Proceso Terapéutico**: Explicación visual del proceso de evaluación, intervención y seguimiento
- **Sistema de Contacto**: Formularios optimizados para captación de pacientes potenciales
- **Sección FAQ**: Respuestas a dudas frecuentes de padres sobre el proceso terapéutico
- **Optimización Móvil**: Experiencia completamente responsiva
- **Optimización SEO**: Estructura pensada para posicionamiento local

## Arquitectura Técnica

La aplicación está construida con tecnologías modernas enfocadas en rendimiento y escalabilidad:

- **Frontend**: Next.js con React para una arquitectura moderna basada en componentes
- **TypeScript**: Tipado estático para mejorar mantenibilidad y calidad del código
- **Tailwind CSS**: Sistema de diseño consistente basado en design tokens
- **Framer Motion**: Animaciones sutiles para mejorar la experiencia de usuario
- **Component Architecture**: Estructura modular reutilizable
- **Design System**: Implementación de paleta de colores basada en la identidad visual de Lúdico
- **Performance Optimization**: Optimización de carga e imágenes

## Retos Únicos

- Traducir servicios terapéuticos complejos a un lenguaje claro para padres
- Crear una estructura de contenido enfocada en confianza y conversión
- Diseñar una identidad digital coherente con el branding infantil profesional de Lúdico
- Implementar una arquitectura escalable para futuras funcionalidades
- Crear una experiencia visual que combine lo clínico con lo emocional

## Diseño y Experiencia de Usuario

La experiencia de usuario fue diseñada bajo principios de UX para servicios de salud infantil:

- **Diseño Centrado en Padres**: Lenguaje claro y estructura enfocada en resolver preocupaciones reales
- **Jerarquía Visual Profesional**: Uso de espacios, tipografía y colores para mejorar legibilidad
- **Identidad Visual Coherente**: Uso de la paleta de marca Lúdico para mantener consistencia
- **Microinteracciones**: Animaciones sutiles para mejorar engagement
- **Accesibilidad**: Buen contraste y legibilidad en todos los dispositivos
- **Mobile First**: Diseño optimizado primero para dispositivos móviles
- **SEO Local**: Optimización para búsquedas relacionadas con terapia infantil en Barranquilla
- **Optimización de Conversión**: CTAs estratégicos para agendamiento de valoraciones

## Resultados del Proyecto
