# Lúdico BQ

Lúdico BQ is a professional website developed for a pediatric occupational therapy clinic specialized in sensory feeding therapy, food selectivity, and sensory integration. The platform is designed to educate parents, build trust, and facilitate patient acquisition through a clear, professional, and user-centered digital experience.

The project aims to position Lúdico as a reference in pediatric feeding therapy in Barranquilla, highlighting the more than 20 years of experience of occupational therapist Jazmín Rojas.

## Key Features

- **Service Presentation**: Clear information about feeding therapy, sensory integration, and family support
- **Professional Profile**: Dedicated section showcasing Jazmín Rojas’ experience, background, and therapeutic approach
- **Therapy Process**: Visual explanation of the evaluation, intervention, and follow-up process
- **Contact System**: Optimized forms for capturing potential patients
- **FAQ Section**: Answers to common parent questions about the therapy process
- **Mobile Optimization**: Fully responsive experience across all devices
- **SEO Optimization**: Structure designed for local search positioning

## Technical Architecture

The application is built with modern technologies focused on performance and scalability:

- **Frontend**: Next.js with React for a modern component-based architecture
- **TypeScript**: Static typing to improve maintainability and code quality
- **Tailwind CSS**: Consistent design system based on design tokens
- **Framer Motion**: Subtle animations to enhance user experience
- **Component Architecture**: Reusable modular structure
- **Design System**: Brand color palette implementation based on Lúdico's visual identity
- **Performance Optimization**: Image and loading optimizations

## Unique Challenges

- Translating complex therapeutic services into clear language for parents
- Creating a content structure focused on trust and conversion
- Designing a digital identity aligned with Lúdico’s professional pediatric branding
- Implementing a scalable architecture for future features
- Creating a visual experience that balances clinical professionalism with emotional warmth

## Design and User Experience

The user experience was designed following UX principles for pediatric healthcare services:

- **Parent-Centered Design**: Clear language and structure focused on solving real concerns
- **Professional Visual Hierarchy**: Use of spacing, typography, and colors to improve readability
- **Consistent Visual Identity**: Brand color implementation to maintain design consistency
- **Microinteractions**: Subtle animations to improve engagement
- **Accessibility**: Good contrast and readability across devices
- **Mobile First**: Design optimized primarily for mobile devices
- **Local SEO**: Optimization for searches related to pediatric therapy in Barranquilla
- **Conversion Optimization**: Strategic CTAs for therapy evaluation bookings

- Improved perception of professional authority
- Platform ready for patient acquisition
- Scalable technical foundation for future improvements
